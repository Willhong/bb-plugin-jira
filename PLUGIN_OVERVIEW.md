Work with Jira Cloud issues from BB, and let agents keep Jira up to date without
touching it behind your back.

## What you get

- A **Jira** page with your issues grouped by In progress, To do, and Done,
  and saved views for assigned, reported, and recently updated issues. Filter by
  project or text, or write JQL.
- An issue view where you edit the title, description, status, assignee,
  priority, labels, and comments in place, and delete issues after confirming.
- **Send to agent** starts a thread with the issue and your instructions.
- The same browser as a thread side panel, and `@` mentions for issues.
- Agent tools to search, read, create, edit, transition, comment, assign, and
  delete.

## Project links

Link a BB project to its Jira projects, and that project's chats and Jira side
panel only see those issues. Agents can still search all of Jira when you ask
about something else.

## Agent permissions

Agents ask before each kind of change by default. Set create, edit, status,
comment, assignee, and delete to **Ask every time** or **Always allow**
separately, from the plugin settings, the page's permissions button, or the
approval card itself. The setting applies to every project. Your own edits on
the page never ask.

## Setup

Jira Cloud only. Enter your site (`acme.atlassian.net`), your Atlassian email,
and an API token from id.atlassian.com → Security → API tokens. The token stays
on the BB server.
